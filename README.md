# Вместе в школу

Интерактивный дашборд на Python и Dash для варианта № 17 «Процесс управления социальными проектами». Данные описывают адресную помощь школьникам по модели из лабораторных работ Wiki и BPMN. Показатели охватывают взносы по СБП, закупки фонда, выдачу вещей и отправку отчётов.

## Запуск на Windows

Требуется Python 3.12 или совместимая версия. Команды запускаются из папки репозитория.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте `http://127.0.0.1:8050`. Нажмите **Загрузить CSV** и выберите [пример](data/example.csv) или свой файл той же структуры. Также можно скачать пример из интерфейса. При открытии страницы дашборд ждёт файл. При ошибке загрузки показывается причина, а последние успешно обработанные данные остаются доступны до перезагрузки вкладки.

## Элементы дашборда

| Элемент | Как пользоваться |
| --- | --- |
| Фильтры | Выберите период, одну или несколько категорий вещей и способов помощи. Пустой список означает все значения. Периоды в днях отсчитываются от последней даты во всём файле включительно. |
| Четыре индикатора | Показывают сумму подтверждённых взносов, оплаченных закупок, количество выданных вещей и число отправленных отчётов в выбранной выборке. |
| Поступления и закупки | Сравните две суммы по неделям с денежными операциями. Наведите курсор на точку, чтобы увидеть сумму. Нажмите название ряда в легенде, чтобы скрыть или вернуть его. |
| Структура закупок | Наведите курсор на сектор, чтобы увидеть сумму и долю категории. Щёлкните категорию в легенде, чтобы изменить видимость сектора. |
| Распределение взносов | Проверьте, какие интервалы сумм встречаются чаще всего. Подсказка показывает интервал и число операций. |
| Взносы и закупки по неделям | Каждая точка сопоставляет суммы за одну неделю. Подсказка показывает начало недели и обе суммы. |
| Сводка по категориям | Нажмите значок сортировки у заголовка столбца. При наличии более восьми строк используйте переключатель страниц. |

Закупки учитываются по фактическим расходам фонда. Личная передача вещей и прямая покупка на маркетплейсе отражаются в натуральных показателях. Расходы и взносы могут приходиться на разные недели. Дашборд суммирует фактические события за выбранный период.

## Формат CSV

Поддерживаются UTF-8, UTF-8 с BOM и Windows-1251. Разделитель — точка с запятой или запятая. Десятичную запятую при разделителе-запятой заключайте в кавычки. Максимальный размер — 2 МБ, максимум 10 000 строк данных. Каждая строка описывает одну операцию.

| Столбец | Содержание |
| --- | --- |
| `date` | Дата `ГГГГ-ММ-ДД` |
| `position_id` | Обезличенный идентификатор позиции, например `P-0017` |
| `category` | Категория вещей, например `Рюкзаки` |
| `channel` | `personal` — личная передача, `marketplace` — онлайн-покупка, `sbp` — денежный взнос |
| `event` | `donation` — подтверждённый взнос, `purchase` — закупка фонда, `accepted` — приём вещей, `delivered` — выдача семье, `reported` — отправка отчёта |
| `amount` | Сумма в рублях для `donation` и `purchase`. Для остальных событий — `0` или пустое значение |
| `quantity` | Целое положительное число для `accepted` и `delivered`. Для остальных событий — `0` или пустое значение |

`donation` и `purchase` относятся к каналу `sbp`. `accepted` относится к `personal` или `marketplace`. Выдача и отправка отчёта возможны во всех трёх каналах. В примере 537 синтетических событий по 165 позициям с апреля по ноябрь 2026 года. В нём нет персональных данных семей и благотворителей.

## Ветки

`main` содержит начальный коммит. Разработка ведётся в `test`. Проверенная версия переносится слиянием в `release`.
